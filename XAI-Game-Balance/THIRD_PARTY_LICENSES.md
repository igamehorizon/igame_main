# Third-party components

The Game Balance Tool uses the following open-source components. They are not included in this download; they are installed from the Python Package Index (PyPI) on first start, each under its own license.

| Component | Purpose | License |
|---|---|---|
| [FastAPI](https://github.com/fastapi/fastapi) | Analysis service (API) | MIT |
| [Uvicorn](https://github.com/encode/uvicorn) | Server for the analysis service | BSD-3-Clause |
| [python-multipart](https://github.com/Kludex/python-multipart) | File uploads | Apache-2.0 |
| [Pydantic](https://github.com/pydantic/pydantic) | Data validation | MIT |
| [NumPy](https://github.com/numpy/numpy) | Numerical computing | BSD-3-Clause |
| [pandas](https://github.com/pandas-dev/pandas) | Data processing | BSD-3-Clause |
| [scikit-learn](https://github.com/scikit-learn/scikit-learn) | Gradient Boosting, K-Means | BSD-3-Clause |
| [SHAP](https://github.com/shap/shap) | Explainable AI | MIT |
| [Streamlit](https://github.com/streamlit/streamlit) | User interface | Apache-2.0 |
| [Requests](https://github.com/psf/requests) | Communication between interface and service | Apache-2.0 |

These packages install further dependencies of their own (for example SciPy and Numba), each under its own license.

Fonts loaded by the interface from Google Fonts: [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) and [Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono), both under the SIL Open Font License 1.1.
